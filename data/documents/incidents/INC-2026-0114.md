# Payment failures on salary day - connection pool exhausted again

**Incident ID:** INC-2026-0114
**Date:** 2026-01-14
**Severity:** SEV1
**Affected service:** card-payment-gateway
**Duration:** 50 minutes

## Customer impact
Card and wallet payments failed for about 12% of customers on salary day.

## Timeline
- 12:00 Salary credits start
- 12:10 Timeout errors
- 12:35 Pool resized
- 13:00 Recovered

## Root cause
After the October incident the pool size was increased manually on the servers but NOT in the Helm chart. The December redeploy reset it to 50. Salary-day peak exhausted the pool again.

**Root cause category:** database connection pool exhaustion

## Corrective actions
- Pool size is now in the Helm chart (config as code).
- Add a drift check in the pipeline.
